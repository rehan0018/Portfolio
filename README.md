# Rehan Shaikh — Personal Digital Cosmos Portfolio

> **"An engineer exploring the intersection of software, technology, ideas, and the universe."**  
> Building software, exploring systems, and staying curious about the ideas behind them.

A production-quality, minimalist 3D interactive portfolio website engineered with React, TypeScript, Vite, Tailwind CSS, Three.js, and React Three Fiber.

---

## Architecture & Visual Concept

- **Core Metaphor**: A navigable personal digital cosmos:
  - **Central Space**: Engineering identity and introduction.
  - **Stars**: Core ideas and clickable architectural principles.
  - **Planets**: Important engineering projects orbiting along celestial paths.
  - **Constellations**: Interconnected technology trees (Software, Systems, Cloud & Reliability, Intelligence).
  - **Orbits**: Career and learning trajectory (Past → Present → Next).
- **Aesthetic**: Observatory + engineering laboratory + night sky. Near-black graphite (`#07090D`), midnight atmospheric gradients, steel blue accents (`#8FAFC4`), and muted gold highlights (`#C8A96B`).

## Featured Systems & Projects

All projects are grounded in verified public GitHub repositories:

1. **[Edufeedia](https://github.com/rehan0018/Edufeedia)**: AI-powered safe learning platform (ages 10–17) with Socratic RAG, fail-closed multi-category safety guardrails, and SuperMemo SM-2 spaced repetition for active recall.
2. **[Alaadin](https://github.com/rehan0018/Alaadin)**: Autonomous AI payment recovery agent optimizing Expected Recovery Value (ERV) with hard merchant policy veto boundaries, Redis idempotency, and direct banking status verification.
3. **[aneAI](https://github.com/rehan0018/AneAI)**: Clinical anesthesia risk intelligence and patient survival prediction using XGBoost, FastAPI, and Explainable AI (SHAP).
4. **[Campus Crown](https://github.com/rehan0018/Crown)**: Campus-exclusive social network with verified student authentication, gamified title voting, real-time leaderboards, and department feeds.
5. **[E-Commerce Platform](https://github.com/rehan0018/E_commerce_poject_clg)**: Full-stack digital commerce application with inventory catalog and checkout.
6. **[Shree Ram Vadapav](https://github.com/rehan0018/Shree_Ram_Vadapav)**: Lightweight, mobile-first web showcase and ordering interface.

## Tech Stack

- **Framework**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, CSS Glassmorphism
- **3D & Graphics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Icons**: Lucide React
- **Performance**: Instanced particle systems, adaptive DPR clamp, reduced-motion query support, dedicated mobile layout

## Local Development

```bash
# Clone repository
git clone https://github.com/rehan0018/Portfolio.git
cd Portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build
```
